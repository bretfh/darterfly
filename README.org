#+TITLE: finch

A live, hackable operating system on SBCL with Unix semantics: processes, file
descriptors, signals, pipes and sockets. A small C core boots the machine,
owns the page tables, traps and the scheduler; everything above it, from the
VFS and the network stack to the window server and the apps, is Common Lisp
you can change while it runs.

Some designs come from macOS because they are good ones: Mach ports and
launchd, IOKit-style driver matching, APFS, a layer compositor, and xnu's
system call numbers as the line between SBCL's runtime and the kernel. macOS 26
Tahoe and xnu sit on the reference shelf (=finch/tahoe=); finch does not try
to look or behave like macOS. Icons and fonts are GNOME's Adwaita.

* Running it

#+begin_src sh
  make repl
  make check   # loads with no warnings from finch's own code
  make test    # the whole suite, including boots of the image under QEMU
  make bare    # build the image and boot it
#+end_src
