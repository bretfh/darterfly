#+TITLE: Darterfly

A live, hackable operating system for x86-64, written in Common Lisp from the
boot loader up and running on SBCL. The loader and the kernel (boot, paging,
traps, the scheduler, SMP) are written in a restricted Lisp compiled to machine
code by SBCL's own assembler. Above them, processes, Mach-style ports, the file
system, drivers, TCP/IP, the window server and the apps are ordinary Common
Lisp you can change while it runs.

Its shape is inspired by macOS more than by the BSDs: the whole experience is
part of the system, from the kernel through the window server, the compositor
and the desktop apps, rather than a terminal with a desktop borrowed from other
software. The terms are its own.

It builds itself: a running system compiles its compiler, runtime, kernel and
loader from source, installs the result as a new generation, and boots it.
Icons and fonts are GNOME's Adwaita.

* Running it

#+begin_src sh
  make repl
  make check   # loads with no warnings from darterfly's own code
  make sbcl    # first build: prepare the SBCL compiler/core used by the bootable image
  make test    # the whole suite, including boots of the image under QEMU
  make bare    # build the image and boot it to a REPL on the terminal
  make desktop # the desktop in a window, on build/darterfly-hd.img, which keeps your files
#+end_src

See [[file:ROADMAP.org][the roadmap]], [[file:TASKS.org][the task list]], and [[file:release/PLATFORMS.org][reference platforms]].
