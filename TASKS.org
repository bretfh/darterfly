#+TITLE: Darterfly task list

Tasks are ordered by dependency and risk. Checkboxes describe delivered work;
qualification requires evidence, not just an implementation. See [[file:ROADMAP.org][the roadmap]].

* Milestone 1: release baseline
- [X] Pin public Guix/nonguix channels separately from workstation-local channels.
- [X] Capture source revision, dirty status, exact source archive, and source hash.
- [X] Isolate source, build output, HOME, and compilation caches for every run.
- [X] Record tool versions, resolved package manifest, firmware hashes, and host.
- [X] Separate host, guest, recovery, and smoke test selection; preserve make test.
- [X] Retain stage status/duration/output and per-console serial logs/command lines.
- [X] Package version-identified artifacts with SHA-256 checksums.
- [X] Boot-test the exact output image with snapshot writes and no embedded nREPL key.
- [X] Collect repeated raw metrics and count/min/median/p95/max, retaining errors.
- [X] Measure boot-to-init, console roundtrip, GUI key-to-draw observation, memory,
  GC, rendering, storage sync, disk write throughput, and TCP receive throughput.
- [X] Add automated checks for evidence generation and failed/timeout commands.
- [X] Publish a platform/capability matrix and a physical qualification protocol.
- [X] Validate the pinned pipeline end-to-end and record its evidence bundle
  ([[file:release/VALIDATION.org][validation report]]).
- [ ] Run the full guest and recovery release gate on a clean committed revision.
- [ ] Query arraniz model/revision/firmware and attach dated hardware evidence.
- [ ] Measure physical keyboard-to-screen latency (console roundtrip is separate).
- [ ] Compare two independent full builds; remove remaining nondeterminism before
  claiming bit-identical disk/core images.

* Release blockers found by the baseline
- [ ] REL-001: detect the injected interior-object pointer and refuse the damaged

- [ ] REL-002: complete erase-and-install-over-an-installed-system without losing
  the system-world heartbeat and resetting. Keep watchdog protection enabled.
Evidence and reproduction: [[file:release/VALIDATION.org][validation report]]. These block make release.
