#+title: Shared OCICL source adaptations

Darterfly packages OCICL's vendored sources through manifest.scm. Nyxt
loads that same pure-tls/cl+ssl-compat system without loading the OCICL
CLI. These adaptations belong to the shared package, not a second TLS
implementation in Nyxt.

* Verified connections and session tickets

The pinned pure-tls 1.10.0 accepts a fresh verified TLS 1.3 connection,
but its automatic ticket resumption fails on the next connection. This
was reproduced on both native Darterfly and host SBCL against OpenSSL.
The host rejected the PSK binder. Inspection found that the truncated
ClientHello is rewrapped with a shortened handshake length, contrary to
[[https://www.rfc-editor.org/rfc/rfc8446.html#section-4.2.11.2][RFC 8446 section 4.2.11.2]]. An experimental correction exposed a second
parse of an already-decoded ServerHello extension. Correcting that in
the experiment then reached the existing required-verification check,
which rejects a resumed handshake because it has no certificate.

Those experimental protocol changes are not shipped. The packaged
patch gates ticket lookup to connections whose verification mode is
none. Verified connections perform a full certificate handshake on
every connection. The cache holds neither a peer certificate chain nor
its verification policy; accepting cached authentication would need a
larger upstream change. The patch does not relax certificate checks.

The tradeoff is extra work on new connections. HTTP keep-alive remains
available. WebKit's separate, qualified native TLS backend is unchanged.
OCICL's pure-tls implementation supports TLS 1.3 only.

Remove the guard when an updated upstream package passes repeated
verified requests, certificate-policy changes, invalid-certificate
rejection and HelloRetryRequest interoperability. Do not remove the
required-verification check to make session resumption succeed.

After editing the patch, refresh Guix's cached manifest environment
before building:

#+begin_src sh
guix shell --rebuild-cache -m manifest.scm -- true
#+end_src

* Regression checks

The host check loads the exact packaged source from GUIX_ENVIRONMENT.
It performs two requests to a normal TLS 1.3 server and two to a server
that forces HelloRetryRequest. The origin records whether sessions
resumed. The guest Nyxt check additionally rejects expired, future,
wrong-host and untrusted certificates, then requests a valid page again.
